# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| x.x.x   | :white_check_mark: |

## Reporting a Vulnerability

> [!WARNING]
> Due to the reduced number of developers, vulnerability might not be fixed
> right away, help is appreciated!

Open an issue and add all of the necessary details to reproduce the
vulnerability so that we can check and fix the latter with the highest priority
possible.
